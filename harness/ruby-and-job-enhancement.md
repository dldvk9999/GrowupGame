# 루비 & 전직스킬 강화 (migration 142/143, 신규 콘텐츠, 사용자 요청)

관련 파일: `RubyDungeonBattle.jsx`, `lib/rubyDungeon.js`, `lib/jobSkillEnhance.js`, `SkillLoadout.jsx`(전직강화 탭), migration 142/143

## 루비 던전

새 재화 "루비"를 얻는 전용 던전. 기존 던전들과 다른 점:

- **순차 진행이 아니라 단발성**: 경험치/골드 던전(층 진행)이나 전직 던전(차수별 순차 클리어)과 달리, 루비 던전은 "매번 새 세션으로 보스 1마리와 싸우는" 구조 — 층이나 단계 개념이 없음
- **캐릭터 레벨에 자동 스케일**: `calc_ruby_dungeon_boss(level)` — `hp = 1500 + level^1.5×40`, `atk = 80 + level^1.3×6`, `def = 60 + level^1.2×4`. 별도 진행도 요구조건 없이 지금 레벨 그대로 도전 가능
- **하루 5회 제한**(`ruby_dungeon_attempts`, 다른 일일 던전과 동일하게 Asia/Seoul 08:00 리셋)
- **클리어 보상 10~100개 랜덤 루비**(`10 + floor(random()*91)`)
- 세션 기반 클레임(`start_ruby_dungeon`/`claim_ruby_dungeon_reward`)에 "생성 후 최소 1초" 안티치트 게이트 — 전직던전(140에서 3초→1초로 완화)과 동일한 이유로 처음부터 1초로 설정
- 전투 화면(`RubyDungeonBattle.jsx`)은 `JobDungeonBattle.jsx`를 기반으로 새로 작성(기존 컴포넌트를 건드리면 검증된 전직던전 로직에 리스크가 생기므로, 복사 후 보상 로직만 교체하는 방식을 택함) — 적 스프라이트는 별도 그래픽 없이 이모지(`enemy.icon`)로 표시(간단하고 안전한 선택)

## 전직 스킬 강화

전직(각성) 스킬은 원래 고정 배율이었는데, 루비를 소모해서 강화할 수 있게 됨:

```
강화 1레벨당 배율 +2%p (JOB_SKILL_ENHANCE_PER_LEVEL)
최대 50강
강화 비용 = 전직차수 × 10 + 현재레벨 × 전직차수 × 2   -- (calc_job_skill_enhance_cost)
```

- **등급(=전직 차수)이 높을수록 강화 비용이 비쌈**(사용자 요청) — 예: 1차 전직 스킬 0강→1강은 10루비, 10차 전직 스킬 0강→1강은 100루비. 같은 강화레벨이어도 차수가 높으면 비용이 그 차수만큼 배로 늘어남
- **확률 실패 없음** — 유물과 달리 루비를 내면 항상 성공(레벨만 오름). 안전장치는 "비용이 갈수록 비싸진다"는 점진적 증가뿐
- `job_skill_enhancements` 테이블(user_id, skill_id, level) — 스킬 하나하나가 독립적으로 강화됨(예: 1차 전직 스킬과 10차 전직 스킬은 각자 별도로 강화 필요)
- 서버 `enhance_job_skill`이 `owned_monsters.unlocked_job_tier`로 "실제로 그 전직을 마쳤는지"까지 검증 — 아직 안 배운 스킬은 강화 불가

### 스킬편성 화면의 "전직강화" 탭

`SkillLoadout.jsx`에 탭을 신설(사용자 요청: "스킬편성 탭 내 전직강화 탭") — 기존 단일 화면을 "🧩 편성"(기존 슬롯 편성 UI 그대로)과 "💎 전직강화"(신규) 두 개로 분리. 전직강화 탭은 `getUnlockedJobTiers`로 실제 습득한 전직 스킬만 나열해서, 각 스킬의 현재 강화레벨/다음 강화 비용/강화 버튼을 보여줌.

## 전투 반영 범위 (⚠️ 알려진 제한)

강화 배율은 `getEnhancedJobSkillMultiplier(skill, enhancements)`로 계산되는데, **이번엔 시간 관계상 아래 두 곳에만 반영**했고 나머지는 범위 밖으로 남김(유물의 쿨감%/버프%가 던전/전직던전/월드보스에 미반영인 것과 같은 성격의 문서화된 제한):

| 화면 | 반영 여부 |
|---|---|
| `BattleScreen.jsx`(메인 스테이지, 자동사냥 스테이지 진행 포함) | ✅ 반영 |
| `RubyDungeonBattle.jsx`(루비 던전 자체) | ✅ 반영(처음부터 새로 만든 컴포넌트라 포함시킴) |
| `DungeonBattle.jsx`(경험치/골드/무한의탑 던전) | ❌ 미반영 |
| `JobDungeonBattle.jsx`(전직 던전) | ❌ 미반영 |
| `WorldBossBattle.jsx`(월드보스) | ❌ 미반영 |
| 서버 PvP 전투력 계산(`calc_combat_power`) | ✅ 반영됨(171, `calc_skill_possession_bonus`). 전직스킬 강화 자체는 여전히 미반영(전직스킬 개별 강화치까지 PvP에 반영하려면 추가 작업 필요) |

## 데이터 표시

- 보유 루비는 마이페이지("보유 루비" 행)와 루비 던전 탭·전직강화 탭 안에 각각 표시. 헤더의 상시 골드 표시줄에는 추가하지 않음(모바일 헤더가 이미 여러 요소로 붐벼서, 루비는 상대적으로 특수 목적 재화라 관련 화면 안에서만 보여주는 쪽을 택함)
