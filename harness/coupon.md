# 쿠폰 목록

`redeem_coupon(code)` RPC로 입력하면 보상이 **우편함으로** 지급됨(즉시 지급 아님). 발행/시스템 동작 방식 자체(테이블 구조, 레이스컨디션 수정 이력 등)는 [`mailbox-and-coupons.md`](./mailbox-and-coupons.md)의 "쿠폰 시스템" 절 참고 — 이 문서는 **실제 발행된 쿠폰 코드 목록**만 관리하는 단일 진실 공급원.

> ⚠️ **새 쿠폰을 발행할 때마다 이 표에 행을 추가할 것.** 코드/보상/최대사용횟수/만료일/발행 사유(관련 migration 번호)를 빠짐없이 기록한다. `mailbox-and-coupons.md`에는 쿠폰 시스템의 동작 방식만 남기고 개별 쿠폰 목록은 중복 기재하지 않는다(이 파일이 유일한 출처).

## 새 쿠폰 발행 방법

```sql
insert into public.coupons (code, gold_amount, item_key, max_uses, expires_at)
values ('원하는코드', 10000, null, 100, '2026-12-31'::timestamptz);
```

- `item_key`는 `null`이면 골드만 지급, 특정 아이템키(`무기_에픽` 형태 등)를 넣으면 골드+아이템 동시 지급
- `max_uses`는 `null`이면 무제한
- `expires_at`은 `null`이면 만료 없음

발행 후 반드시:
1. 이 파일(`coupon.md`)의 표에 행 추가
2. `database-schema.md`에 해당 migration 요약 한 줄 추가
